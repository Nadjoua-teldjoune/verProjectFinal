Tool Overview

The tool allows you to analyze execution traces and detect architectural tactics.

  • Upload a file containing traces
  • Detect architectural tactics
  • Display results in a readable format
  • View the history of recent traces

Supported File Types

The tool accepts .txt and .log files. Formats like .csv or .json are not yet supported.

User Guide

  1. Upload a trace: Click on "Upload a file" and select a .txt file.
  2. Select a tactic: Click on a tactic to see an example.
  3. Run the analysis: The tool analyzes the structure and detects tactics.
  4. View history: The tool keeps the last 3 traces.

Frequently Asked Questions

Use the editing area and paste your text or upload a file in .txt or .log format.

The tool only supports .txt and .log files. Any other format will not be recognized.

The results show the matches between your trace and the detected architectural tactics.

Common Issues and Solutions

Upload Issues

Unsupported file → Make sure the file is a .txt file.

Empty file → Open it in a text editor to confirm its content.

Issues with JavaCC

Parsing error → Check the syntax of your trace.

Dashboard Overview

The Dashboard provides a comprehensive overview of key metrics and comparisons for your architectural analysis. It includes performance, security, reliability, complexity, and maintainability scores, as well as a detailed comparison of the tactics used in your traces. This tool helps you quickly identify strengths and areas for improvement in your system’s architecture.

🗑 History Management

The tool saves the most recently analyzed traces. You can delete them at any time.
